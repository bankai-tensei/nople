# Security

[日本語は下にある](#日本語)

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub: on the repository page, open **Security**, then **Report a vulnerability**. Include what is affected, how to reproduce it, and the impact you see.

You will get an answer within a week. Once a fix is ready, it is released and the report is published with credit to you, unless you ask otherwise.

## Supported versions

Only the latest release gets security fixes.

## 日本語

セキュリティの問題は、公開の issue に書かないでください。GitHub の非公開の報告を使ってください。リポジトリのページで **Security** を開き、**Report a vulnerability** から送ります。影響を受けるもの、再現の手順、考えられる影響を書いてください。

1 週間以内に返事をします。修正ができたらリリースし、希望が無ければ報告者の名前を添えて報告を公開します。

セキュリティの修正は、最新のリリースにだけ入れます。
